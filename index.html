workspace-storage connects the owner's personal server to Google Drive using rclone, with encryption applied before file contents are uploaded.

What the application does

This personal application creates and manages an encrypted workspace in the owner's Google Drive. It supports uploading, listing, downloading, renaming and deleting files through rclone. Nextcloud is the intended browsing interface; integration with local and remote storage is being developed.

This website provides application information. It does not provide account registration, a file browser or a Google sign-in form.

Google Drive access

The application requests https://www.googleapis.com/auth/drive.file so it can manage files created by or explicitly authorized for this application. Google authorization is completed using rclone on the owner's devices.

Rclone's crypt feature encrypts file contents, filenames and subfolder names before storage in Drive. The enclosing workspace folder name and some storage metadata remain visible to Google.

Read the Privacy Policy for details about access, storage and deletion.

Terms of use

This is a personal-use integration operated by the GitHub account saipr0. It is not offered as a public storage service.
